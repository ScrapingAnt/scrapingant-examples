The self-authored HTML fixture is generated by `fixture_server.py` and binds only to 127.0.0.1 on an ephemeral port. It uses publicly documented provider TEST keys, not account secrets. The local backend calls the real provider verification endpoint. An empty token is rejected locally before that call. Turnstile rejection/duplicate results are explicitly forced with its documented test secrets; they do not measure production token security.

Internet access is required for Google and Cloudflare widget scripts and verification endpoints. No public fixture deployment is needed.
